# IQS / IQSTRC

เว็บแอป PHP สำหรับคัดกรองการสูบบุหรี่ แผนเลิกบุหรี่ E-Learning เกมความรู้ รายงาน และเกียรติบัตร มีหน้าสมาชิกและหน้าผู้ดูแลระบบ

## ติดตั้งไว้ที่ไหน

| รายการ | เครื่องพัฒนา | เซิร์ฟเวอร์ผู้ว่าจ้าง |
| --- | --- | --- |
| ไฟล์เว็บ | `C:\xampp\htdocs\iqstrc\program` | `/htdocs` ในบัญชี FTP ของ IQS |
| หน้าสมาชิก | `http://localhost/iqstrc/program/` | https://iqs.trc.or.th/ |
| หน้าแอดมิน | `http://localhost/iqstrc/program/admin/login.php` | https://iqs.trc.or.th/admin/login.php |
| ฐานข้อมูล | `iqstrc` บน XAMPP | `iqsdb` บนโฮสต์ผู้ว่าจ้าง |
| ตั้งค่าฐานข้อมูล | `program/admin/indyEngine/dbStructure.php` | `/htdocs/admin/indyEngine/dbStructure.php` |

เว็บจริงวาง **ไฟล์และโฟลเดอร์ข้างใน `program/`** ลง `/htdocs` โดยตรง จึงไม่มี `/program/` ใน URL จริง ไฟล์ตั้งค่าของเครื่องกับโฮสต์ใช้ค่าคนละชุด ห้ามทับค่าของโฮสต์ด้วยค่าของ XAMPP

ช่องทางอัปไฟล์ที่ตรวจแล้ว: FTPS แบบ explicit TLS, โฮสต์ `ns30.appservhosting.com`, พอร์ต `21` ใช้บัญชีที่ผู้ว่าจ้างส่งให้แยกต่างหาก ไม่เก็บรหัสผ่านไว้ในโปรเจกต์

ระบบเป็น PHP โดยตรง ไม่ต้องรัน npm หรือ build ก่อนอัป ใช้ PHP 8.2 พร้อม `mysqli`, `mbstring`, `gd`, `fileinfo` และ MySQL/MariaDB เว็บจริงตรวจพบ PHP 8.2.32, MySQL 9.2.0 และใช้ Redis เก็บ session; เครื่องพัฒนาใช้ session แบบไฟล์ได้

## เปิดในเครื่อง / ติดตั้งใหม่

1. วางโปรเจกต์ไว้ที่ `C:\xampp\htdocs\iqstrc` แล้วเปิด Apache และ MySQL ใน XAMPP
2. สร้างฐานข้อมูล `iqstrc` ใน phpMyAdmin และเลือกฐานนี้ก่อน Import
3. สำหรับเครื่องทดสอบ ใช้ `database/iqstrcheal_iqstrc.safe.sql` ซึ่งปกปิดข้อมูลสมาชิกแล้ว หรือใช้ `database/iqstrcheal_iqstrc_schema.sql` เมื่อต้องการเฉพาะโครงสร้าง เลือกอย่างใดอย่างหนึ่งและนำเข้าฐานว่างเท่านั้น ไฟล์โครงสร้างอย่างเดียวจะยังไม่มีบทเรียน สมาชิก หรือบัญชีแอดมิน
4. การย้ายข้อมูลจริงต้องใช้ไฟล์ SQL ฉบับเต็มที่ส่งมอบแยกแบบส่วนตัว ไม่ใช้ไฟล์ `.safe.sql` แทนข้อมูลจริง และต้องย้าย `program/uploads/` มาด้วย
5. แก้ `$host`, `$db_user`, `$db_password`, `$db_name` ใน `program/admin/indyEngine/dbStructure.php` ให้ตรงกับฐานที่สร้าง ระบบหลักอ่านค่าจากไฟล์นี้ ไม่ใช่จาก `.env`
6. ให้ PHP เขียน `program/uploads/` และ `program/uploads/images/` ได้ และตั้งค่าที่เก็บ session ให้ใช้งานได้ ไม่ต้องเปิดสิทธิ์ `777`
7. เปิดหน้าสมาชิกหรือแอดมินตามตารางด้านบน บัญชีแอดมินให้ใช้บัญชีที่เจ้าของระบบอนุญาต ไม่มีรหัสผ่านระบุใน README

## อัปเดตเว็บจริง

1. แก้และทดสอบใน localhost ก่อน
2. สำรองไฟล์เว็บ ฐานข้อมูล และ `uploads/` บนโฮสต์ก่อนอัป
3. ส่งเฉพาะไฟล์เว็บที่เปลี่ยนผ่าน FTPS ไป `/htdocs` ห้ามอัปค่าฐานข้อมูลของเครื่อง ไฟล์ SQL, `.env`, `.git`, `DB/`, `database/`, `deploy/` หรือเครื่องมือทดสอบไปไว้ในเว็บ
4. ถ้ามีรูปใหม่ ให้อัปเพิ่มในตำแหน่งเดิม **ไม่ลบโฟลเดอร์ `uploads/` และไม่ลบรูปเก่าที่ไม่มีในเครื่อง**
5. หากต้องแก้โครงสร้างฐานข้อมูล ให้ใช้ SQL migration เฉพาะจุดหลังสำรอง ห้าม Import ฐานตัวอย่างหรือ dump เก่าทับฐานที่มีสมาชิกใช้งาน
6. ตรวจล็อกอิน สมัครสมาชิก คัดกรอง บันทึกเลิกบุหรี่ E-Learning/ประวัติ วิดีโอ เกม รายงาน เกียรติบัตร และหน้าแอดมินหลังอัป

## ข้อมูลและการดูแล

- ฐานจริงมี 19 ตาราง ประเภท/ระดับผู้สมัครเก็บใน `user.applicant_type` และ `user.applicant_level`; ประวัติและคำตอบ E-Learning เก็บใน `elearning` (`q1` ถึง `q17`)
- ยังเก็บตารางมหาวิทยาลัย/คณะเดิมไว้เพื่อรักษาข้อมูลเก่า ไม่ควรลบเพียงเพราะหน้าสมัครเปลี่ยนแล้ว
- รหัสผ่านใหม่เก็บแบบแฮช รหัสผ่านเดิมเปลี่ยนเป็นแฮชเมื่อเจ้าของบัญชีล็อกอินสำเร็จ ไม่ต้องตั้งรหัสใหม่ให้สมาชิกเดิม
- ข้อมูล SQL เต็ม รูปสมาชิก รหัสผ่าน และไฟล์สำรองเป็นข้อมูลภายใน ห้ามเผยแพร่ใน repository สาธารณะ

## สถานะตรวจล่าสุด

อัปชุดแอปเมื่อ 4 ตุลาคม 2569: ดาวน์โหลดกลับมาเทียบกับ localhost 142 ไฟล์ตรงกัน โครงสร้างฐานข้อมูลที่ฟีเจอร์ปัจจุบันต้องใช้มีครบ โดยไม่ทับข้อมูลสมาชิกเดิม วันที่ 5 ตุลาคมตรวจเว็บจริงซ้ำ 106 คำขอผ่าน และตรวจว่าไฟล์ในเครื่องยังตรงกับชุดที่อัปไว้

ยังต้องตรวจรับแอดมินและการสมัคร/อัปโหลดครบประเภทบนเว็บจริง จัดการข้อมูล QA หลังได้รับอนุญาต ยืนยันชุดข้อมูลส่งมอบ และกู้รูปที่ยังขาด 31 ไฟล์ (แบนเนอร์ 3 / รูปสมาชิก 28) ชื่อ `www.iqs.trc.or.th` ยังไม่มี DNS วันที่ 5 ตุลาคม ให้ใช้ URL แบบไม่มี `www` ข้างต้นจนกว่าผู้ดูแลโดเมนจะตั้งค่า

หลักฐานและไฟล์สำรองอยู่ใน `deploy/` บนเครื่องผู้พัฒนา ซึ่งไม่ส่งขึ้น Git รายงานรายละเอียด: `deploy/trc-handover-status-20261004.md`
